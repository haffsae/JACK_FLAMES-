### Project Description
[JACKFLAMES combines image uploading, interactive web design, and a playful AI concept to create a funny and entertaining compatibility experience.

Users upload their photo and a jackfruit photo, and the website generates a humorous compatibility result.]

### The Problem (that doesn't exist)
[Have you ever wondered:

**"Am I compatible with a jackfruit?"** 🍈😂

There was absolutely no scientific method to answer this extremely important question.

So we decided to solve this completely unnecessary problem.]

### The Solution (that nobody asked for)
[JACKFLAMES analyzes the uploaded images and generates a random, funny compatibility score.

The result includes:

- ❤️ Compatibility percentage
- 😂 Funny messages
- 🍈 Jackfruit-themed results
- 🎉 Entertaining visual output

Because sometimes technology should just be fun!]

# Installation
[1. Download or clone the JACKFLAMES repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the project folder.
4. Open `index.html` in a web browser.]


# Run
[1. Open `index.html`.
2. Upload a person's photo.
3. Upload a jackfruit photo.
4. Click the compatibility button.
5. View the generated JACKFLAMES result.]
